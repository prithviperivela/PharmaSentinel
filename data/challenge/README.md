# Synthetic diagnostic suite

Twenty original, fictional language examples generated by `scripts/create_challenge.py`.
Ten are development diagnostics; ten are reserved for the frozen evaluation procedure.
They use fictional medicine names and describe linguistic associations, not actual drug effects.

Rubric: a textually asserted or speculative suspected adverse association is an adverse candidate;
an explicitly beneficial treatment association is therapeutic. A negated association, a medicine
mention without an effect, or an effect explicitly predating treatment is no event under this
diagnostic rubric. The rubric may differ from some PHEE annotation conventions.

This is a small self-authored challenge suite, not expert clinical annotation or a representative
sample of biomedical writing. It is suitable for identifying weaknesses, not estimating deployment
accuracy. Development/final examples share categories and schematic constructions; the final set
is a held-out diagnostic, not independent external validation.
